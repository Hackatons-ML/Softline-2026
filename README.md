# AIForge — Умный поиск, допродажи и аналитика каталога для Store.softline.ru

Решение для хакатона **ИИкузница** (трек **«Аналитик данных»**, задача **«Умный поиск на сайте»**).

---

## Что решает система

Стандартный поиск `store.softline.ru` ищет точные текстовые совпадения по описаниям, из-за чего до **40% запросов** заканчиваются пустой или нерелевантной выдачей (например, по слову `сервер` выдаются серверные лицензии СЭД вместо физического серверного оборудования, по `astra linux` — чужие сертификаты техподдержки, а по `365` — случайные артикулы `-519365`).

**AIForge** превращает поиск в интеллектуального консультанта и инструмент допродаж + даёт категорийным менеджерам полноценную аналитику спроса и качества каталога:

1. **Понимание смысла, сленга, раскладки и опечаток (`< 100 мс`)**:
   - Гибридное ранжирование: локальная нейросетевая модель мультиязычных эмбеддингов `multilingual-e5-small` (ONNX Runtime, 384d) + полевой `BM25F` + `RapidFuzz` + автопереключение раскладки (`fcnhf kbyerc` → `astra linux`) + очистка кириллических/латинских букв-двойников (`Сontent AI`, `webinаr`) + словарь ИТ-жаргона и ребрендингов (`антивирь`, `винда`, `офис`, `мдаемон`, `акронис` → *Кибер Бэкап*, `мтс` → *МТС Линк / Webinar*).
2. **Разделение интента «Оборудование vs ПО» и защита от ловушки «X для Y»**:
   - По запросу `сервер` агент по умолчанию выводит физические стоечные серверы (`Серверы и опции`, `электроника`) и предлагает интерактивные чипсы уточнения (*Серверное оборудование* / *Серверные ОС и ПО* / *Комплектующие и СХД*).
   - Сопутствующие товары вида *«КриптоПро CSP для Astra Linux»* не засоряют 1-е место по запросу `astra linux`, а автоматически переносятся в блок **допродажи**.
3. **Гарантия `≥ 4 товаров` в каждом ответе**:
   - Двухуровневая группировка `136 040` SKU в продуктовые линейки (как по софту `group_id`, так и по оборудованию без `group_id`) с каскадным расширением конфигураций и аналогов гарантирует минимум 4 релевантные позиции на любой запрос.
4. **Инструмент допродажи (Cross-Sell, Upsell, Акции, Выгодная цена и Импортозамещение)**:
   - Блок **«Часто покупают вместе»** опирается на майнинг совместимости из каталога и верифицированные внешние источники вендоров (*Ready for Astra* `astra.ru`, `cyberprotect.ru`, `kaspersky.ru`, `cryptopro.ru`, `ptsecurity.com`, `mts-link.ru`, `usergate.com`).
   - Расчет реальных бейджей **«Акция −X%»** (`oldprice > price`) и **«Выгоднее средней цены по разделу на X%»**, а также подбор доступных аналогов из **Реестра ПО РФ** для ушедших зарубежных брендов (`67.2%` фида имеют `available="false"`).
5. **Живые товарные подсказки уже во время ввода (Бонус)**:
   - Эндпоинт `/api/suggest` за `< 30 мс` прямо во время набора текста предлагает исправление опечатки, категории, 4 карточки товаров с ценами и спецпредложение со скидкой.
6. **Кабинет аналитика данных + экспорт `.xlsx`**:
   - Воронка спасенных запросов и интерактивный калькулятор возвращаемой выручки (в млн ₽/год), реальный аудит дефектов `Mindbox.yml.gz.xml` (гомоглифы, опечатки категорий, «мертвые» разделы) и выгрузка готового Excel-отчета для категорийных менеджеров.

## Быстрый запуск одной командой

Требования: Python 3.11+ (протестировано на Python 3.14, Windows). Собранный интерфейс уже находится в `frontend/dist` (Node.js для запуска не обязателен).

```powershell
pip install -r requirements.txt
# Поместите исходный фид Mindbox.yml.gz.xml (292 МБ, исключён из Git из-за лимита GitHub 100 МБ) в корень проекта
python run.py
```

Откройте в браузере: **http://127.0.0.1:8000**

*(При самом первом запуске, если папка `storage/` ещё не создана, скрипт автоматически проиндексирует `Mindbox.yml.gz.xml` и загрузит ONNX-веса `Xenova/multilingual-e5-small`.)*
